# GitHub 本周趋势回顾：2026-09-14 至 2026-09-20 热门项目精选

本周 GitHub 趋势榜单显示，AI 编程 Agent 及其配套生态系统占据了绝对的主导地位。从 Anthropic 官方推出的终端工具到各种性能优化和技能库，开源社区正加速进入“Agent 驱动”的开发新时代。

## 热门项目精选

### 1. [open-code-review](https://github.com/alibaba/open-code-review)
- **Owner**: alibaba
- **Language**: Go
- **Stars (Weekly)**: 15,504
- **简介**: 阿里巴巴开源的高效代码审查工具，经过大规模实战检验。它采用混合架构，结合了确定性流水线与 LLM Agent，能够提供精准的行级评论。内置多语言规则集（如 NPE、线程安全、SQL 注入检测），并兼容 OpenAI 与 Anthropic 模型。

### 2. [claude-code](https://github.com/anthropics/claude-code)
- **Owner**: anthropics
- **Language**: TypeScript
- **Stars (Weekly)**: 2,342
- **简介**: Anthropic 推出的终端 Agent 编程工具。它直接运行在命令行中，能够深刻理解代码库，通过自然语言指令执行例行任务、解释复杂逻辑并自动化处理 Git 工作流，极大地提升了开发效率。

### 3. [ECC](https://github.com/affaan-m/ECC)
- **Owner**: affaan-m
- **Language**: JavaScript
- **Stars (Weekly)**: 6,453
- **简介**: 针对 AI 编程 Agent 的性能优化系统。它为 Claude Code、Codex、Cursor 等工具提供了核心的“技能、直觉、记忆和安全”框架，是构建更强大编程助手的重要基石。

### 4. [WeKnora](https://github.com/Tencent/WeKnora)
- **Owner**: Tencent
- **Language**: Go
- **Stars (Weekly)**: 5,242
- **简介**: 腾讯开源的 LLM 知识平台。它能将各种格式的原始文档转化为可查询的 RAG（检索增强生成）系统、一个能够自主推理的 Agent，以及一个能够自我维护的 Wiki 知识库。

### 5. [agent-skills](https://github.com/addyosmani/agent-skills)
- **Owner**: addyosmani
- **Language**: JavaScript
- **Stars (Weekly)**: 3,986
- **简介**: 由 Addy Osmani 发起的项目，专注于为 AI 编程 Agent 提供生产级别的工程技能。这些标准化的技能集可以帮助 Agent 更稳定地执行复杂的工程任务。

### 6. [knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)
- **Owner**: anthropics
- **Language**: Python
- **Stars (Weekly)**: 1,298

### 7. [gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view)

- **Stars (Weekly)**: 8,111

### 8. [context-mode](https://github.com/mksglu/context-mode)
- **Owner**: mksglu

- **Stars (Weekly)**: 1,242
