# GitHub 本周趋势回顾：2026 第 43 周热门项目精选

本周 GitHub 社区涌现出多个重量级项目，涵盖了逆向工程、AI 开发辅助、系统移植及视频渲染等前沿领域。以下是本周最受关注的 10 个开源项目精选。

## 1. [rea](https://github.com/morluto/rea) - 智能逆向工程工具
- **语言**: TypeScript
- **本周 Stars**: 229,268
- **简介**: `rea` 是一个利用 AI Agent 技术的逆向工程框架。它能够自动化分析应用程序行为，从应用层逻辑一直深入到原生二进制指令。对于安全研究人员和开发者来说，它是理解闭源软件和调试复杂问题的强大助手。

## 2. [artcraft](https://github.com/storytold/artcraft) - 创意设计引擎
- **语言**: Rust
- **本周 Stars**: 16,379
- **简介**: `artcraft` 是一款专为艺术家、设计师和电影制作人设计的创意工程引擎。它通过 Rust 语言的高性能特性，提供了一套深思熟虑的创作逻辑，旨在优化数字艺术和影视内容的制作流程。

## 3. [AnyPS5](https://github.com/boykopovar/AnyPS5) - PS5 跨平台运行工具
- **语言**: C++
- **本周 Stars**: 14,224
- **简介**: `AnyPS5` 致力于将 PS5 的可执行文件自动移植到 Linux 和 Windows 平台。作为一项极具技术挑战的工程，它吸引了大量系统开发者的关注，也为跨平台游戏和应用兼容性带来了新的可能。

## 4. [claude-plugins-official](https://github.com/anthropics/claude-plugins-official) - Claude Code 官方插件库
- **语言**: Python
- **本周 Stars**: 4,774
- **简介**: 由 Anthropic 官方维护的高质量 Claude Code 插件目录。随着 Claude 在编码领域的普及，官方提供的插件生态将极大地增强 AI 开发工具的可扩展性和功能深度。

## 5. [context-mode](https://github.com/mksglu/context-mode) - AI 编码上下文优化器
- **语言**: TypeScript
- **本周 Stars**: 4,138
- **简介**: 专门为 AI 编码代理（Coding Agents）设计的上下文窗口优化工具。它能够减少 98% 的冗余输出，持久化会话记忆，并通过 MCP（模型上下文协议）跨 17 个平台强制路由，极大提升了 AI 编码的效率和准确度。

## 6. [diagram-design](https://github.com/cathrynlavery/diagram-design) - 纯净图表设计库
- **语言**: HTML
- **本周 Stars**: 7,901
- **简介**: 专为 Claude Code、Cursor 等 AI 编码工具设计的示意图库。包含 44 种图表类型，采用自包含的 HTML + SVG 格式，摒弃了传统的阴影和 Mermaid 复杂逻辑，追求极致的简洁与直观，非常适合嵌入 AI 生成的文档中。

## 7. [ghidra](https://github.com/NationalSecurityAgency/ghidra) - NSA 逆向工程框架
- **语言**: Java
- **本周 Stars**: 7,602
- **简介**: 由美国国家安全局（NSA）开发的著名软件逆向工程（SRE）框架。作为行业标杆，Ghidra 持续保持高热度，为漏洞分析、病毒查杀和底层研究提供全套的拆解和分析工具。

## 8. [hyperframes](https://github.com/heygen-com/hyperframes) - 网页化视频渲染引擎
- **语言**: TypeScript
- **本周 Stars**: 5,883
- **简介**: HeyGen 团队推出的新工具，允许开发者通过编写 HTML 来渲染视频。这套框架专为 AI Agent 设计，使得程序化生成视频内容变得像构建网页一样简单直观。

## 9. [plugins](https://github.com/cursor/plugins) - Cursor 插件规范与合集
- **语言**: TypeScript
- **本周 Stars**: 1,717
- **简介**: 热门 AI 编辑器 Cursor 的官方插件规范及官方插件仓库。它定义了 Cursor 生态的扩展标准，是开发者深度定制 AI 编程环境的重要参考。

## 10. [ai-job-search](https://github.com/MadsLorentzen/ai-job-search) - AI 自动化求职框架
- **语言**: Python
- **本周 Stars**: 5,742
- **简介**: 这是一个运行在本地的自动化求职神器，基于 Claude Code 构建。它能评估职位描述、定制简历、撰写自荐信并协助面试准备。开发者可以 Fork 并完全掌控自己的求职数据和流程。
