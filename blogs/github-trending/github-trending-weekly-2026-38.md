# GitHub 本周趋势回顾：2026-W38 热门项目精选

本周 GitHub 依然是 AI Agent 和生产力工具的天下。从上下文优化到自动架构图绘制，开源社区正在全力加速 AI 辅助编程的进化。

## 热门项目精选

### 1. [i-have-adhd](https://github.com/ayghri/i-have-adhd)
- **语言**: Python
- **本周 Stars**: 16,740
- **简介**: 为编程助手设计的“反废话”技能。通过优化输出，让回答更直接、更具针对性，非常适合追求极致效率、厌倦冗长解释的开发者。

### 2. [ECC](https://github.com/affaan-m/ECC)
- **语言**: JavaScript
- **本周 Stars**: 7,264
- **简介**: 针对主流编程助手（如 Claude Code, Codex 等）的性能优化系统。涵盖了技能、本能、内存管理和安全性增强，是目前 Agent 领域的前沿架构方案。

### 3. [gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view)
- **语言**: JavaScript
- **本周 Stars**: 12,931
- **简介**: 在浏览器中实现的“间谍卫星”模拟器。它不仅仅是视觉模拟，更集成了真实的全球空间智能数据，在 3D 地球上提供照片级的实时观测体验。

### 4. [ponytail](https://github.com/DietrichGebert/ponytail)
- **语言**: JavaScript
- **本周 Stars**: 8,444
- **简介**: 贯彻“最好的代码就是没写的代码”这一资深开发者哲学。该项目旨在引导 AI 助手像最“懒”的架构师一样思考，编写最精简、可维护性最高的核心逻辑。

### 5. [archify](https://github.com/tt-a1i/archify)
- **语言**: JavaScript
- **本周 Stars**: 10,132
- **简介**: 为 Agent 专门打造的架构图绘制技能。它可以直接生成包含平滑动效的可交互 HTML 流程图，支持高清导出，让复杂的系统设计逻辑瞬间清晰。

### 6. [hyperframes](https://github.com/heygen-com/hyperframes)
- **语言**: TypeScript
- **本周 Stars**: 5,146
- **简介**: 由 HeyGen 团队出品。允许通过编写 HTML/代码直接渲染视频，专为 AI Agent 生成多媒体内容而设计，极大降低了自动化视频生产的门槛。

### 7. [markitdown](https://github.com/microsoft/markitdown)
- **语言**: Python
- **本周 Stars**: 5,191
- **简介**: 微软开源的高效工具，可将各类 Office 文档和多种文件格式完美转换为 Markdown。是构建 RAG（检索增强生成）知识库和文档迁移的利器。

### 8. [context-mode](https://github.com/mksglu/context-mode)
- **语言**: TypeScript
- **本周 Stars**: 2,102
- **简介**: AI 编程助手的“上下文清理大师”。通过沙盒化工具输出，可实现高达 98% 的冗余缩减，并支持跨 17 个平台的 MCP 路由。

### 9. [skills](https://github.com/openai/skills) & [plugins](https://github.com/openai/plugins)
- **语言**: Python / JavaScript
- **简介**: OpenAI 官方维护的技能与插件库，展示了 LLM 扩展能力的标准范式和无限可能，是开发者深入了解官方生态的必读参考。
