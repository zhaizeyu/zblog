# GitHub 本周趋势回顾：2026-06-30 至 2026-07-06 热门项目精选

本周 GitHub 趋势榜单显示，AI 驱动的安全、投资研究和开发工具依然占据主导地位。以下是本周最受关注的 10 个开源项目。

## 1. [strix](https://github.com/usestrix/strix)
- **Owner**: usestrix
- **Language**: Python
- **本周新增 Stars**: 10338
- **简介**: strix 是一款开源的 AI 渗透测试工具，旨在帮助开发者发现并修复应用程序中的漏洞。通过集成 AI 能力，它能更智能地模拟攻击场景，并提供具体的修复建议，是现代安全开发生命周期中的有力补充。

## 2. [ai-berkshire](https://github.com/xbtlin/ai-berkshire)
- **Owner**: xbtlin
- **Language**: Python
- **本周新增 Stars**: 5038
- **简介**: 这是一个专为 AI 时代设计的价值投资研究框架。它基于 Claude Code 和 Codex，融合了巴菲特、芒格、段永平、李录等投资大师的方法论，通过多 Agent 并行研究，为投资者提供深度、多维度的财务分析和投资建议。

## 3. [OmniRoute](https://github.com/diegosouzapw/OmniRoute)
- **Owner**: diegosouzapw
- **Language**: TypeScript
- **本周新增 Stars**: 4411
