# GitHub 本周趋势回顾：2026-08-03 至 2026-08-09 热门项目精选

在本周的 GitHub 趋势榜单中，我们看到了 AI Agent 记忆管理、逆向工程自动化以及高效 PDF 处理工具的强劲表现。以下是本周最受关注的 10 个开源项目。

## 1. [reverse-skill](https://github.com/zhaoxuya520/reverse-skill)
- **语言**: PowerShell
- **本周 Stars**: 9784
- **简介**: 这是一个专为逆向工程、授权渗透测试和安全研究设计的 AI 技能路由包。它支持自举工具链和自动进化经验库，能够无缝集成到 Claude Code、Cursor 等 AI 编码客户端中，极大提升了安全研究人员的工作效率。

## 2. [pdf-inspector](https://github.com/firecrawl/pdf-inspector)
- **语言**: Rust
- **本周 Stars**: 8641
- **简介**: 由 Firecrawl 开发的高性能 Rust 库，用于 PDF 的快速检查、分类和文本提取。它具备智能检测扫描件与文本型 PDF 的能力，帮助开发者在处理海量文档时做出更精准的路由决策。

## 3. [TencentDB-Agent-Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory)
- **语言**: TypeScript
- **本周 Stars**: 8003
- **简介**: 腾讯云推出的团队级 AI Agent 记忆中心。它能将对话、文档和代码转化为可复用的记忆资产（聊天记忆、技能、LLM-Wiki、代码图谱），实现跨 Agent 和框架的记忆共享与治理。

## 4. [AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners)
- **语言**: Jupyter Notebook
- **本周 Stars**: 5514
- **简介**: 微软出品的 AI 入门课程，涵盖 12 周共 24 节课。无论你是学生还是开发者，这套课程都能通过由浅入深的内容带你领略人工智能的全貌，是目前最受欢迎的 AI 教育资源之一。

## 5. [airllm](https://github.com/lyogavin/airllm)
- **语言**: Jupyter Notebook
- **本周 Stars**: 5129
- **简介**: 突破硬件限制的杰作。AirLLM 允许在仅有 4GB 显存的单张 GPU 上运行 70B 参数规模的大型语言模型。对于预算有限但希望在本地运行高性能模型的开发者来说，这是一个不可多得的工具。

## 6. [DeepSeek-Reasonix](https://github.com/esengine/DeepSeek-Reasonix)
- **语言**: Go
- **本周 Stars**: 4709
- **简介**: 基于 DeepSeek 原生能力的终端 AI 编码助手。针对前缀缓存稳定性进行了深度优化，非常适合在终端环境中长时间运行，为开发者提供实时、稳定、深度的代码逻辑推理支持。

## 7. [book-to-skill](https://github.com/virgiliojr94/book-to-skill)
- **语言**: Python
- **本周 Stars**: 4121
- **简介**: 这是一个非常实用的工具，可以将任何技术书籍的 PDF 转换为 Claude Code 可识别的“技能”。这意味着你可以直接让 AI 助手学习并引用书籍内容，将其应用到你的实际工作中。

## 8. [kaneo](https://github.com/usekaneo)
- **语言**: TypeScript
- **本周 Stars**: 1952
- **简介**: 一个开源的项目管理工具，主打“恰到好处”的功能设计。它剔除了繁琐的流程，只保留真正有用的协作功能，旨在让项目管理服务于你的工作，而不是让你被管理流程束缚。

## 9. [skills](https://github.com/google/skills)
- **语言**: Python
- **本周 Stars**: 1626
- **简介**: 谷歌官方发布的针对其产品和技术的 Agent 技能库。为开发者提供了丰富的预置能力，可以快速构建能够与 Google 生态系统深度交互的 AI 智能体。

## 10. [swarm-forge](https://github.com/unclebob)

- **本周 Stars**: 562
