# GitHub 本周趋势回顾：2026 第 29 周热门项目精选

本周 GitHub 上的开源社区依然火热，特别是在 AI 代理（Agents）、协作工具以及高性能系统组件方面涌现了许多值得关注的项目。以下是本周最受瞩目的 Top 10 项目精选。

---

### 1. [meetily](https://github.com/Zackriya-Solutions/meetily)
- **语言**: Rust
- **本周增加 Stars**: 7440
- **简介**: 隐私优先的 AI 会议助手。它基于 Rust 构建，提供比同类产品快 4 倍的实时转录（使用 Parakeet/Whisper）、发言人识别以及本地 LLM（通过 Ollama）摘要功能。100% 本地处理，无需云端，是 macOS 和 Windows 用户最安全的 AI 会议记录选择。

### 2. [DesktopCommanderMCP](https://github.com/wonderwhy-er/DesktopCommanderMCP)
- **语言**: TypeScript
- **本周增加 Stars**: 1678
- **简介**: 专为 Claude 设计的 MCP（Model Context Protocol）服务器。它赋予了 AI 终端控制权、文件系统搜索以及差异化文件编辑能力，让 AI 能够更深度地参与到本地开发流程中，实现真正的自动化协作。

### 3. [codex-plugin-cc](https://github.com/openai/codex-plugin-cc)
- **语言**: JavaScript
- **本周增加 Stars**: 2803
- **简介**: OpenAI 推出的插件，允许通过 Claude Code 调用 Codex。该项目旨在加强不同 AI 生态之间的互操作性，让开发者在进行代码审查或任务委派时，能更灵活地利用 Codex 的代码理解能力。

### 4. [CubeSandbox](https://github.com/TencentCloud/CubeSandbox)
- **语言**: Rust
- **本周增加 Stars**: 2490
- **简介**: 腾讯云开源的即时、并发、安全且轻量级的 AI Agent 沙箱环境。它为 AI 代理执行代码提供了一个隔离的运行空间，在保证安全性的同时，将启动延迟降到了最低。

### 5. [abseil-cpp](https://github.com/abseil/abseil-cpp)
- **语言**: C++
- **本周增加 Stars**: 600
- **简介**: Google 开源的 C++ 标准库补充集。Abseil 提供了一系列高性能、高质量的 C++ 组件，旨在增强 C++ 标准库的功能，是大型 C++ 项目提升效率和稳定性的首选底层库。

### 6. [herdr](https://github.com/ogulcancelik/herdr)
- **语言**: Rust
- **本周增加 Stars**: 3928
- **简介**: 运行在终端中的 Agent 多路复用器。它可以让你同时管理和调度多个 AI 代理执行任务，就像在终端中使用 tmux 一样方便地管理你的 AI 劳动力。

### 7. [system_prompts_leaks](https://github.com/asgeirtj/system_prompts_leaks)
- **语言**: JavaScript
- **本周增加 Stars**: 7155
- **简介**: 一个专门收集和更新各大 AI 模型（如 Claude 3.5/4/5、ChatGPT GPT-5.6、Gemini 3 等）系统提示词（System Prompts）的仓库。对于想要研究大型语言模型运行逻辑和工程化提示词的开发者来说极具参考价值。

### 8. [OmniRoute](https://github.com/diegosouzapw)
- **语言**: TypeScript
- **本周增加 Stars**: 4506
- **简介**: 免费的 AI 网关。它提供统一的端点连接超过 231 个提供商，支持将 Claude Code、Cursor、Cline 等工具连接到免费的 AI 接口。通过独特的压缩技术，它可以节省 15-95% 的 Token 消耗，并支持智能自动回退。

### 9. [orca](https://github.com/stablyai/orca)
- **语言**: TypeScript
- **本周增加 Stars**: 4481
- **简介**: 针对并行 Agent 集群设计的开发环境（ADE）。它允许你在桌面和移动端通过自己的订阅运行任何编程 Agent，大大降低了大规模 Agent 协作的门槛。

### 10. [claude-video](https://github.com/bradautomates/claude-video)
- **语言**: Python
- **本周增加 Stars**: 4353
- **简介**: 为 Claude 增加了“看”视频的能力。该工具可以自动下载视频、提取关键帧、进行语音转录，并将其整合后交给 Claude 处理，让 AI 能像理解文字一样理解视频内容。
