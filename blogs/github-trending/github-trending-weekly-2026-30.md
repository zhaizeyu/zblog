# GitHub 本周趋势回顾：热门项目精选 (2026-W30)

本周 GitHub 社区依然保持着极高的活跃度，尤其是在 AI Agent 相关技能、视频编辑以及交易辅助工具方面涌现了不少令人眼前一亮的项目。以下是本周最受关注的前 10 个开源项目精选。

## 1. [hallmark](https://github.com/Nutlope/hallmark)
- **作者**: Nutlope
- **语言**: CSS
- **本周新增 Stars**: 9193
- **简介**: 这是一个专为 Claude Code、Cursor 和 Codex 等 AI 编程助手设计的“反 AI 废话（Anti-AI-slop）”设计技能库。它通过特定的 CSS 和样式约束，帮助开发者在使用 AI 生成代码时保持界面的纯净和设计的一致性，减少冗余输出。

## 2. [OpenCut](https://github.com/OpenCut-app/OpenCut)
- **作者**: OpenCut-app
- **语言**: TypeScript
- **本周新增 Stars**: 12743
- **简介**: 作为 CapCut（剪映）的开源替代品，OpenCut 提供了强大的视频编辑功能。它采用 TypeScript 构建，旨在为创作者提供一个跨平台、高性能且完全透明的视频编辑解决方案，本周人气极高。

## 3. [awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)
- **作者**: Shubhamsaboo
- **语言**: Python
- **本周新增 Stars**: 6211
- **简介**: 该仓库收集了超过 100 个可以直接运行、克隆和自定义的 AI Agent 与 RAG（检索增强生成）应用。对于想要快速上手 AI 应用开发，或是寻找项目灵感的开发者来说，这无疑是一座金矿。

## 4. [Vibe-Trading](https://github.com/HKUDS/Vibe-Trading)
- **作者**: HKUDS
- **语言**: Python
- **本周新增 Stars**: 5228
- **简介**: 香港大学数据科学实验室（HKUDS）推出的个人交易助手。正如其名 "Vibe-Trading"，它结合了先进的数据分析和可能的市场情绪感知技术，旨在为个人投资者提供智能的交易决策支持。

## 5. [DeepTutor](https://github.com/HKUDS/DeepTutor)
- **作者**: HKUDS
- **语言**: Python
- **本周新增 Stars**: 2375
- **简介**: 同样来自 HKUDS 的作品，DeepTutor 专注于实现终身个性化辅导。通过 AI 技术，它能够根据学习者的进度和反馈提供定制化的教学内容，是教育 AI 领域的又一力作。

## 6. [skills](https://github.com/mattpocock/skills)
- **作者**: mattpocock
- **语言**: Shell
- **本周新增 Stars**: 10983
- **简介**: 来自著名开发者 Matt Pocock 的分享，直接从他的 `.agents` 目录导出的“真实工程师”技能库。这些脚本涵盖了日常开发流程中的多种自动化任务，实用性极强，本周吸引了大量关注。

## 7. [cangjie-skill](https://github.com/kangarooking/cangjie-skill)
- **作者**: kangarooking
- **语言**: Python
- **本周新增 Stars**: 1284
- **简介**: 一个非常有意思的项目，旨在将书籍、长视频、播客等高价值内容“蒸馏”成可执行的 AI Agent 技能。它帮助用户将静态知识转化为动态的、可交互的助手能力，提升了知识利用效率。

## 8. [OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)
- **作者**: iOfficeAI
- **语言**: C#
- **本周新增 Stars**: 4269
- **简介**: OfficeCLI 是首个专门为 AI Agent 设计的 Office 套件命令行工具，支持阅读、编辑和自动化 Word、Excel 及 PowerPoint 文件。它无需安装 Office 软件，作为单一二进制文件运行，非常适合集成在自动化流水线中。

## 9. [ui-skills](https://github.com/ibelick/ui-skills)
- **作者**: ibelick
- **语言**: TypeScript
- **本周新增 Stars**: 1669
- **简介**: 专为设计工程师准备的技能库，聚焦于 UI/UX 的快速实现和组件交互。对于追求极致视觉效果和交互体验的前端开发者来说，是一个非常好的参考。

## 10. [codex](https://github.com/openai/codex)
- **作者**: openai
- **语言**: Rust
- **本周新增 Stars**: 2361
- **简介**: OpenAI 推出的在终端运行的轻量级编程助手。使用 Rust 编写，保证了极高的运行效率和响应速度，进一步降低了开发者在命令行环境下使用 AI 的门槛。
